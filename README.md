# Litops Atelier

Production-версия интернет-магазина браслетов ручной работы из натуральных
камней. Сайт подготовлен для GitHub Pages и домена `litopsatelier.ru`.

## Возможности

- Next.js 16, React 19 и TypeScript;
- полностью статический экспорт без зависимости от ChatGPT Sites;
- главная, каталог, 11 карточек товаров, корзина и избранное;
- оформление и индивидуальный заказ, контакты и локальная панель управления;
- адаптивная вёрстка, Lenis-прокрутка и поддержка `prefers-reduced-motion`;
- локальные изображения без Google Fonts и внешних медиахостингов;
- sitemap, robots.txt, Open Graph и SEO-метаданные;
- автоматическая сборка и публикация через GitHub Actions;
- корректная работа как по техническому адресу Pages, так и на собственном домене.

## Локальная проверка

Требуется Node.js 22 или новее.

```bash
npm ci
npm run check
```

Готовый статический сайт создаётся в каталоге `out/`.

## Публикация

Workflow `.github/workflows/deploy-pages.yml` собирает и публикует сайт после
каждого обновления ветки `main`. В `Settings → Pages` источником публикации
должен быть выбран `GitHub Actions`.

После первого успешного запуска в `Settings → Pages → Custom domain` укажите
`litopsatelier.ru`, сохраните и затем замените DNS-записи у REG.RU на адреса
GitHub Pages. После проверки домена включите `Enforce HTTPS`.

## Ограничение прототипа

Корзина, избранное, заявки и демонстрационная панель управления используют
`localStorage`. Они сохраняются только в браузере конкретного посетителя и пока
не отправляют реальные заказы владельцу магазина. Для коммерческого запуска
потребуется подключить backend или внешний обработчик формы.
